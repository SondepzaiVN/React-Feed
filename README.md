# Mini Newsfeed (React + Vite)

Một demo newsfeed đơn giản lấy cảm hứng từ Threads, gồm phần thông tin cá nhân, kỹ năng và danh sách bài viết.

## Tính năng

- Tạo bài viết nhanh với input.
- Danh sách bài viết theo dạng feed.
- Giao diện tối giản, tone đen/trắng.

## Công nghệ

- React
- Vite
- ESLint

## Cài đặt & chạy

```bash
npm install
npm run dev
```

## Gợi ý mở rộng

- Lưu bài viết vào localStorage.
- Thêm đếm ký tự và giới hạn nội dung.
- Upload ảnh (mock) hoặc hashtag.
